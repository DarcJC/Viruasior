# 高刷新率、原生触摸板与闪黑排查

用户确认的目标：1920×1200 @ 120 Hz；设备实际原生横屏像素尺寸 @ 60 Hz。保留 AHB 同缓冲直接提交与 KWin OpenGL。以实际呈现帧率和连续画面完整性验收，不以 mode 名称或面板刷新率代替。

## 已复现

- 原 48 fps 样本只有 2.6 秒；新的 SurfaceFlinger 时间戳收集去重并排除开始前的历史帧。
- 同一会话下，窗口相对睡眠循环约 44 fps，截止时间循环约 60 fps，无限速约 140 fps；后两者实际呈现约 38 和 32 fps。瓶颈在之后的合成/呈现链路。
- 连续 PNG 中右上和左下出现黑块；固定两个角落区域均曾 100% 黑。客体 XGetImage 对应位置有正常像素。先单独比较 0.01 像素和 1 像素圆角，验证 Android RenderEngine 裁剪路径，再根据结果继续定位。
- SurfaceFlinger 显示该自有层为 CLIENT；面板当前 120 Hz。guest XRandR 当前只有 1920×1200 约 60 Hz。每次 flush 串行等待所有活动 Venus context，仍需量化时间，不能直接删去同步。
- 平板键盘触摸板为 Android MOUSE | TOUCHPAD；AVF 提供 useTrackpad / sendTrackpadEvent，现有应用没有启用它。

## 显示设计

1. 保留显式的有界像素预算，提升为 8,388,608 像素、每边 4096；覆盖实际原生尺寸。release 引用仍最多八个，禁止无界缓冲队列。
2. Venus VM 启动配置使用读取到的原生横屏尺寸和 60 Hz，作为 EDID 的原生 mode 和固定 ABS 输入范围；不改写用户磁盘内容或导入元数据。候选 crosvm EDID 增加 1920×1200 @ 120 Hz 的详细时序。旧的小尺寸标准 modes 保留。
3. 显示控制扩展为有界的 width / height / refresh-millihertz mode。只选择客体实际公布的 mode/rate，使用固定 XRandR 参数数组，失败恢复旧 mode/rate。旧尺寸协议保留为兼容入口。
4. UI 分开记录 actual mode 与 presented size，避免把 AHB 的宽高回调误当成刷新率确认。尺寸变化仍等新尺寸首帧后恢复输入；只改变刷新率由客体控制回复确认，不等待不会发生的尺寸回调。
5. 全屏时用窗口局部刷新率请求匹配的 120 Hz mode；失焦/退出时恢复先前窗口属性。屏幕触摸映射沿用固定启动 ABS 范围，鼠标相对比例跟随已提交尺寸。
6. 性能优化仅针对测到的等待或工作。比较时保持同一场景、mode 和同步正确性，不通过省略生产者或消费者同步换帧率。

## 触摸板设计

启用 AVF 独立 trackpad。捕获事件按 SOURCE_CLASS_POSITION 分发到原生 trackpad，保留多指 ID、压力、尺寸和硬件坐标；不套用屏幕视口比例。真实鼠标保留 RELATIVE mouse 路径。先核对本机 AVF 虚拟 trackpad 尺寸与事件约定；若需归一化，只做物理触摸板范围到固定虚拟触摸板范围的转换。失焦、退出全屏、设备移除、切换模式时结束所有活动 slot 与按钮，避免卡住的触点。

## 验收与清理

先写 mode 解析/回滚、预算、窗口刷新率选择和输入路由/多指释放的行为测试。运行 native、guest、Android 单元与构建检查，核对 APK native pin。实机核对 Linux 独立触摸板设备、多指滚动/点击，记录两档 mode 的长窗口帧间隔、分段帧率、CPU 和闪黑区域。若目标未达到，报告实测上限与未解决的瓶颈。最终移除临时探针，保留 VM 数据，提交代码，停止 VM 并关闭应用，让设备按原设置息屏。

## 实施后的结论

见 [完整验证](../../high-refresh-trackpad-validation.md)。圆角比较未解决闪黑，已恢复原值。实际修复通过配套 KWin 效果扩展已有 paint pass 的区域，保持 OpenGL；两档分辨率的连续运动截图均通过。上下文同步请求改为批量发出，完成和错误回复仍全部排空。

API 37 默认捕获为 RELATIVE，需显式请求 ABSOLUTE。本机 AVF 接收 3000×3000 的 getX/getY 坐标，slot 内部加一且压力固定 50；硬件压力无法经该 API 原样传递。最终系统 dump 确认本应用持有 ABSOLUTE；实体手势手感尚未由用户复测。

高刷新率模式和动态切换已通过，实际稳定帧率目标未通过：1920×1200 @ 120 Hz 的长窗口呈现约 39.6 fps，原生完整重绘约 15.2 fps。没有把时序支持等同于性能达标。
