# Viruaisor：双区工作台 UI/UX 实现规格

日期：2026-10-20。

## 已确认的设计决定

用户要求为当前 Android 项目重新设计并实现 UI/UX，使日常功能易于使用，并将调试 UI 独立。通过 grilling 确认：

- 重新设计页面结构和视觉，不沿用已有四页面原型。
- 采用双区工作台，桌面预览和管理面板并排。
- 冷灰与钴蓝的视觉方向，提供深浅主题。
- 工作台展示桌面预览，点击后进入可交互全屏。
- 设置中直接显示「开发与排障」入口。
- 仅通过文字评审，不生成浏览器原型。

本文是 Android 实现的评审规格。现有 `2026-10-20-ui-ux-design.md` 为先前的原型方案，保留原文件，不作为本次实现依据。

## 范围与信息架构

保持当前单虚拟机模型，使用导入包的真实系统名称和配置。实现全部既有功能，不增加多虚拟机、暂停、快照、系统商店、资源调参或文件管理器。

主导航只有「工作台」与「设置」。平板使用窄侧边导航；手机使用底部导航。「开发与排障」是设置内的独立目的地，具有明确的返回入口。

### 工作台

页首显示系统名称、真实运行阶段和简短说明。未导入时显示文件选择器导入引导；只有准备包确实存在时才提供本地准备包导入。

宽度充足时，左侧约占可用内容的三分之二，展示保持客体比例的桌面；右侧为约 320–380 dp 的管理面板，通过「控制／存储／显示」三个页签切换。两个区域各自有明确标题与间距，避免把所有按钮堆在同一滚动页。

宽度不足时改为上下分区：桌面预览在上，管理页签及内容在下，允许垂直滚动，无横向溢出。主操作最小触控区域为 48 dp，窄屏按钮可纵向排列。

桌面尚不可用时，深色舞台内展示对应真实阶段的空状态、启动或环境设置入口。运行时展示实际 Surface；预览点击后进入全屏。不得生成虚假的桌面图、实时指标、使用率或帧率。

管理面板：

| 页签 | 内容与动作 |
| --- | --- |
| 控制 | VM 运行阶段、启动／关闭、导入／替换、系统配置摘要、droid 账户密码 |
| 存储 | 根盘逻辑容量、扩缩入口、共享目录映射与挂载状态、原盘保留与恢复 |
| 显示 | 客体上报的分辨率／刷新率、当前与请求值、切换进度及失败信息、输入与全屏帮助 |

关闭虚拟机与替换现有系统包需要确认，并说明影响。返回应用或离开工作台不隐式停止 VM。

### 交互全屏

进入后隐藏主导航、管理面板和系统栏，不保留固定 header。根据实机评审反馈，使用不占用桌面空间的悬浮退出控件，显示约 2.5 秒后自动收起。顶部保留小型触控手柄，可重新唤出控件。桌面保持客体画面比例，空余区域为黑色。

继续支持 `Ctrl+Shift+Alt+Q` 返回工作台；Android 返回／Home 保留当前切到后台的行为。退出、失焦和模式切换时按现有约束释放输入，不遗留按键、触摸或鼠标按钮。

预览与全屏使用同一个显示宿主和同一后端，同一时刻只允许一个显示消费者。实机回归确认，重新创建消费队列会丢失静止客体的最后画面，因此全屏和页面导航均保持原生 Surface 的父级稳定。设置或诊断显示时，工作台移出可视区域并隐藏其无障碍子树，返回后直接展示原有画面。Activity 隐藏／销毁和 VM 停止时仍遵守原有资源释放。界面不得因导航而调用停止 VM。

### 设置

运行环境区展示 Root、AVF 授权与 AVF 可用性的独立状态，保留 Root 重试和补齐本应用必要 AVF 权限的入口。未满足环境条件时，工作台提供直达入口。不要把正常使用的必要配置藏在诊断界面。

外观支持跟随系统、浅色、深色，选择持久化。关于区显示项目与当前单虚拟机运行方式的简短信息。「开发与排障」入口直接可见，并提示其中包含实验能力和技术诊断。

### 独立诊断中心

集中展示 Root UID、SELinux、su 路径与实现，AVF 原始能力与授权结果，显示桥接开关及状态，Venus 宿主计算验证和 AVF Venus 后端检查。运行详情必须可选择复制，错误可展开查看完整原因。

Root 显示桥接保留当前限制和 Venus 包的自动启用行为。该行为属于现有运行依赖，移动开关不改变其含义。

Venus 验证仅在 VM 停止、未导入、存储空闲、无其他验证和授权操作时开放；AVF 验证还需宿主验证成功。禁用控件旁说明原因。

撤销权限只撤销现有 journal 中记录的新增权限，保持原有授权；需要停止 VM、存储空闲，进行显式确认并说明 Android 可能终止应用。诊断中心不提供任意 Root 命令或系统策略修改入口。

## 状态、反馈与数据约束

沿用 `VmUiState`、`VmRuntime`、`VmService`、`RootRuntime`、`AvfPermissionRuntime`、`VenusHostRuntime` 与 `GuestPasswordRuntime`。UI 不持有 VM 所有权。

- 启动、导入、停止遵守现有 `canStart`、`canImport`、`canStop`，同时避开 GPU 验证、授权和存储的冲突操作。
- 区分 VM 运行、客体 agent 就绪、Surface 连接与客体画面报告。连接成功不标为桌面画面已经显示。
- 长任务展示实际阶段与不确定进度，不伪造完成百分比。失败信息保留，提供可理解的重试或恢复入口。
- 显示模式只使用客体上报值。当前模式、请求模式和呈现尺寸分别处理；切换中禁用重复请求和客体输入，保留后端的失败与回退处理。显示时序不作为实际帧率宣传。
- 根盘显示逻辑容量；共享目录显示 `storage/0 → /mnt/shared`，完整主机路径在详情中展示。挂载状态区分已挂载、未挂载和等待验证。共享目录不可用不单独阻止启动。
- 根盘目标接受 1–1024 GiB 整数，与当前容量相同或不合法时就地报错。运行中说明「关闭 → 调整 → 重新启动」；停止时调整后保持停止。空间和文件系统错误由现有后端反馈。
- 保留原盘至新盘启动验证通过。恢复待处理时持续提示并禁止替换包；仅停止且空闲时开放恢复，确认时说明会放弃新根盘上的改动，共享目录文件不受影响。
- 修改 droid 密码要求 agent 就绪，使用两个遮蔽输入框，遵守现有 UTF-8 128 字节和禁用字符协议，提交中避免重复操作。密码不持久化、不写 Intent 或日志，关闭对话框后清空。

## 视觉与可访问性

浅色使用冷灰背景（约 `#F3F5F9`）、白色表面、深石墨正文与钴蓝主要操作（约 `#3159E4`）。深色使用蓝黑背景与分层石墨表面，提高主要操作的蓝色明度。最终值以可读性及实机效果调整。

桌面舞台始终深色，外围用细边框和温和圆角建立结构。主要动作使用实色按钮，次要操作用描边或文本；危险动作使用错误色和确认对话框。状态同时使用文字和颜色。减少装饰性卡片，保留稳定的排版层级和充足间距。

全中文操作文案，保留必要技术名词。所有图标按钮有中文可访问名称；键盘可聚焦并完成主要操作。对话框能够取消，不依赖悬停。字号增长时允许换行、滚动和纵向重排。

## 实现边界

`MainActivity` 负责 Android 生命周期、窗口／全屏、输入快捷键、调试 Intent 与服务命令连接。应用壳负责导航、外观和对话框状态。工作台、管理页签、设置、诊断与公共组件拆成独立 Compose 文件。

显示宿主继续负责 Surface attach／detach、真实尺寸、输入释放与 Root 显示后端生命周期。界面与运行层以状态和受限回调连接，不改变现有 Root／AVF 权限边界，不修改 guest 或原生图形路径。

## 验收

1. 手机与平板均能使用工作台、三项管理页签、设置及独立诊断中心；无横向溢出，深浅主题可读。
2. 原有导入、启动、停止、桌面全屏、显示模式、密码、根盘容量与恢复功能仍连接真实服务。禁用原因、忙碌、失败和确认反馈可理解。
3. 进入／退出全屏、切换设置和返回工作台不会隐式停止 VM；保留单个显示消费者与输入释放。
4. 关键状态和冲突操作策略有针对性的测试；界面导航与对话框通过 Compose 测试或实机检查验证。
5. 按 `AGENT.md` 执行 `:app:testDebugUnitTest` 和 `:app:assembleDebug`，同步依赖旧 UI 文案的 smoke 脚本。
6. 在已连接 M367FC 上检查布局、主题、导航与可用桌面路径；不为视觉验证进行破坏性系统包替换、根盘恢复或密码修改。设备截图和日志存入忽略的 `.pi/device-debug/`。

基线检查已完成：现有代码的单元测试与 debug APK 构建通过；本机 Android Studio JDK 25 可用于 Gradle，当前终端需要临时设置 `JAVA_HOME`。
