# 双区工作台实施计划

依据已批准的 `2026-10-20-dual-pane-workbench-design.md`。本环境没有 writing-plans 技能，以下为对应的手工实施计划。

1. 先为操作互斥、恢复限制、容量校验及导航／确认流程编写针对性测试，观察新增约束失败。
2. 提取纯 UI 操作策略、共享组件和冷灰／钴蓝深浅主题；外观偏好保存在应用私有设置中。
3. 将桌面显示宿主、工作台管理面板、对话框、设置和诊断中心从 Activity 拆开。保留显示／输入生命周期、既有调试 Intent 及最新 VPN 共享能力。
4. 接入真实服务动作，复查导航与全屏仅改变显示消费者，不改变 VM 所有权。
5. 执行单元测试、debug APK 构建和针对性的 Compose 仪器测试；更新依赖旧页面文案的设备 smoke 检查。
6. 正常停止当前设备 VM，安装 APK；在 M367FC 检查平板布局、窄屏布局、主题、导航、对话框、真实启动／桌面／全屏／停止。截图和日志保存在 `.pi/device-debug/`。
7. 用户要求验证后关闭应用：正常停止 VM，关闭应用，确认应用和相关 VM 进程退出。

不通过实机视觉验证去替换系统包、修改密码、调整根盘或撤销权限；这些流程验证导航、输入校验和取消行为，底层保留现有实现。
